# TwinCore 企业运营管理平台规则执行清单 V1

## 0. 文档定位

本文把前期确认的业务规则整理成智能体可执行的 `if / then / check` 规则。

规则优先级：

1. `P0`：影响主链完整性、财务资金、合同结算、用工合规。
2. `P1`：影响经营分析、数据质量、审批证据、风险提醒。
3. `P2`：优化体验、统计口径、后续扩展。

风险等级先采用：`高`、`中`、`低`。

## 1. 全域基础规则

| 编号 | 优先级 | If | Then | Check/提示 |
|---|---|---|---|---|
| `BASE-001` | P0 | 业务对象引用客户、供应商、部门、员工、项目、合同 | 必须使用对应主档 ID | 只存名称则提示“关系断链” |
| `BASE-002` | P0 | 同一概念未来会新增、停用、分级、变更规则 | 必须建定义表或规则表 | 禁止做死枚举 |
| `BASE-003` | P0 | 对象属于规则、模板、关系 | 必须支持生效期/失效期或版本 | 否则提示“历史不可追溯” |
| `BASE-004` | P0 | 生成发薪、结算、成本、应收等结果 | 必须保存规则快照或可回溯规则 | 否则提示“结果不可解释” |
| `BASE-005` | P0 | 合同签署、开票、回款、付款、验收、员工合同、IP 授权 | 必须有证据或附件 | 否则提示“强事实证据不足” |
| `BASE-006` | P1 | 来源为 Excel、钉钉、历史台账 | 保留来源系统、来源文件、来源行号 | 用于数据清洗追溯 |
